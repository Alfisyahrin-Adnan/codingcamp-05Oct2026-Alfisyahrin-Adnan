# Life Dashboard - Project Specification & AI Exploration Log

## Project Overview
A clean, responsive, and interactive personal Life Dashboard web app built with HTML5, CSS3, and Vanilla JavaScript.

## Core Features Implemented
- **Greeting & Digital Clock**: Real-time clock display with dynamic time-of-day greetings.
- **Focus Timer**: Interactive 25-minute Pomodoro timer with Start, Stop, and Reset controls.
- **To-Do List**: Full CRUD task management persisting state via Browser `localStorage`.
- **Quick Links**: Dynamic bookmark system stored in `localStorage`.

## Technical Stack & Constraints
- Pure HTML5, CSS3, Vanilla JavaScript (No frameworks).
- All data handled client-side via `localStorage`.
- Clean UI/UX hierarchy and responsive layout.
